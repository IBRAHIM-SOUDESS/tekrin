INSTRUCTION POUR LA BIBLIOTHÈQUE QR CODE
========================================

Pour activer la génération de QR Code en local (hors ligne) :

1. Téléchargez la bibliothèque 'phpqrcode' (ex: http://phpqrcode.sourceforge.net/).
2. Extrayez le contenu.
3. Placez le dossier 'phpqrcode' ici, dans le dossier 'lib'.
4. Assurez-vous que le fichier 'lib/phpqrcode/qrlib.php' existe.

Le code est conçu pour détecter automatiquement la bibliothèque.
Si elle n'est pas trouvée, il utilisera une API en ligne (goqr.me) pour que la démo fonctionne immédiatement.
