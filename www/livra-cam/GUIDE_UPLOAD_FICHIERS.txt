GUIDE : COMMENT REMPLACER VOS FICHIERS SUR LE SERVEUR
=====================================================

Méthode 1 : Utiliser le "Online File Manager" (Le plus simple)
--------------------------------------------------------------
1. Connectez-vous à votre compte InfinityFree (Client Area).
2. Cliquez sur le bouton vert "Control Panel" (ou Manage).
3. Cherchez l'icône "Online File Manager" (c'est un dossier jaune) et cliquez dessus.
4. Dans la liste des dossiers, ouvrez le dossier nommé "htdocs".
   (C'est là que se trouve votre site actuel).

POUR AJOUTER/REMPLACER DES FICHIERS :
5. En bas de l'écran, il y a une barre d'outils. Cherchez le bouton "Upload" (flèche vers le haut).
6. Choisissez "Upload File".
7. Une fenêtre s'ouvre sur votre ordinateur. Allez dans votre dossier projet :
   C:\Users\ibrah\Documents\trae_projects\livra-cam
8. Sélectionnez les fichiers modifiés :
   - admin.php
   - index.php
   - print_receipt.php
9. Cliquez sur "Ouvrir" ou "Valider".
10. IMPORTANT : Le système va vous demander : "File already exists. Overwrite?" (Le fichier existe déjà. Remplacer ?).
    -> Cliquez sur "YES" ou "OVERWRITE". C'est ça qui applique la mise à jour.

POUR LE DOSSIER ASSETS (STYLE.CSS) :
1. Dans le File Manager, double-cliquez sur le dossier "assets" pour rentrer dedans.
2. Cliquez sur "Upload" -> "Upload File".
3. Sélectionnez le fichier "style.css" depuis votre ordinateur (dans le dossier assets).
4. Confirmez le remplacement (Overwrite).

Méthode 2 : Utiliser FileZilla (Si vous l'avez installé)
--------------------------------------------------------
1. Ouvrez FileZilla et connectez-vous (Hôte, Identifiant, Mot de passe, Port 21).
2. Dans la fenêtre de DROITE (Serveur), ouvrez le dossier "htdocs".
3. Dans la fenêtre de GAUCHE (Votre PC), naviguez vers :
   C:\Users\ibrah\Documents\trae_projects\livra-cam
4. Faites glisser les fichiers (admin.php, index.php, etc.) de GAUCHE vers la DROITE.
5. Une fenêtre va s'ouvrir : "Fichier déjà existant".
   -> Cochez "Remplacer" (Overwrite).
   -> Cochez "Toujours effectuer cette action pour la file d'attente actuelle".
   -> Cliquez sur OK.
