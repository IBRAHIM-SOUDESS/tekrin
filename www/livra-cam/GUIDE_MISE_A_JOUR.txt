GUIDE DE MISE À JOUR - LIVRA-CAM (Timeline & Reçus)
=====================================================

Vous avez rencontré une erreur "Cannot log in to the MySQL server" sur votre hébergement en ligne.
Voici la procédure complète pour mettre à jour votre site en ligne.

1. PROBLÈME DE CONNEXION PHPMYADMIN (ERREUR "CANNOT LOG IN")
------------------------------------------------------------
Sur InfinityFree/hébergement gratuit :
- Ne vous connectez pas manuellement avec identifiant/mot de passe si possible.
- Allez dans le **Panneau de Contrôle (VistaPanel)**.
- Cherchez la section **DATABASES** -> **phpMyAdmin**.
- Cliquez sur le bouton **"Connect Now"** ou **"Admin"** à côté de votre base de données.
- Cela devrait vous connecter automatiquement.
- Si l'erreur persiste, c'est souvent temporaire sur les serveurs gratuits. Rafraîchissez la page ou attendez 5 minutes.

2. METTRE À JOUR LA BASE DE DONNÉES
-----------------------------------
Une fois connecté à phpMyAdmin en ligne :
1. Cliquez sur votre base de données (ex: `epiz_12345_livracam`).
2. Allez dans l'onglet **Importer**.
3. Choisissez le fichier : `update_history.sql` (qui est dans votre dossier projet).
4. Cliquez sur **Exécuter** (ou Go).
   -> Cela va créer la table 'historique_colis' nécessaire.

3. METTRE À JOUR LES FICHIERS DU SITE
-------------------------------------
Vous devez envoyer les nouveaux fichiers modifiés sur le serveur (via FileZilla ou "Online File Manager").

Fichiers à REMPLACER (écraser les anciens) :
- `admin.php` (Contient la nouvelle logique d'historique et le bouton reçu)
- `index.php` (Affiche la timeline)
- `assets/style.css` (Contient le design de la timeline)

Fichiers à AJOUTER (nouveaux) :
- `print_receipt.php` (Le reçu PDF)

Dossier complet à vérifier :
/htdocs/
  ├── admin.php          (Mise à jour)
  ├── index.php          (Mise à jour)
  ├── print_receipt.php  (Nouveau)
  ├── config.php         (Ne pas toucher si ça marche déjà)
  └── assets/
       └── style.css     (Mise à jour)

4. VÉRIFICATION
---------------
1. Connectez-vous à votre espace admin en ligne.
2. Créez un nouveau colis ou modifiez le statut d'un colis existant.
3. Vérifiez si l'historique s'affiche bien sur la page de suivi client.
4. Testez le bouton d'impression du reçu.
