# Security Policy

## Reporting a Vulnerability

Security and data integrity are core engineering priorities across all projects in this repository ecosystem.

If you discover a security vulnerability, please **do not** open a public GitHub issue. Instead, report it responsibly via email:

- **Contact**: `ibrahimsoudess7@gmail.com`
- **Subject line**: `[SECURITY] <repository-name> — <brief description>`
- **Response target**: Initial acknowledgment within **48 hours**

Please include, where possible:
1. A clear description of the vulnerability and its potential impact.
2. Minimal reproduction steps or a proof of concept.
3. Affected file paths, endpoints, or commit hash.

## Disclosure Process

- Confirmed issues are triaged by severity and patched privately before public disclosure.
- Credit is given to reporters upon request once the fix is released.
